\section{Outline and Contributions}

Building upon the considerations discussed in Section
\ref{sec:state_of_art}, this thesis introduces a novel approach to
\gls{ISS} in medical imaging. The core of this work is a model
designed to adapt its learning process to varying labeler
performance. This is achieved through a unique loss function that
infers optimal segmentation and assesses labeler reliability without
requiring explicit performance inputs. This loss function implicitly
weighs labelers based on their performance, utilizing an intermediate
reliability map. This map enables the model to prioritize information
from reliable labelers while disregarding noisy labels. Consequently,
this methodology diverges from conventional \gls{CNN}-based
segmentation models by eliminating the need for direct supervision of
labeler performance, thereby enhancing its generalizability and
adaptability across diverse datasets and labeler cohorts.

The primary contributions of this research to the field of \gls{ISS}
in medical images are as follows:

\begin{itemize}
  \item The development of a novel loss function for \gls{ISS} tasks.
    This function can infer the best possible segmentation and codify
    labeler reliability without needing separate inputs regarding
    labeler performance or the training of multiple networks.
  \item The creation of a Chained Deep Learning model for \gls{ISS}
    in medical images. This model effectively learns from
    inconsistent labels and demonstrates improved segmentation
    performance, outperforming state-of-the-art approaches on a
    Triple Negative Breast Cancer histopathology dataset.
  \item A mechanism for emulating noisy annotations. This involves
    using network encoding layer weight disturbances to construct a
    crowdsourced version of the well-known Oxford-IIIT Pet Dataset.
  \item A Python package facilitating the use of the proposed loss
    function and architecture within \gls{CNN} models for \gls{ISS}
    tasks in medical images.
    \footnote{https://pypi.org/project/seg\_tgce/}
  \item Mappings of the Triple Negative Breast Cancer and Oxford-IIIT
    Pet Datasets as lazy loaders, integrated into the package for
    immediate use with the proposed loss function.
    \footnote{https://seg-tgce.readthedocs.io/en/latest/experiments.html}
  \item A publicly accessible Github repository containing the source
    code developed for this work.
    \footnote{https://github.com/blotero/seg\_tgce}
\end{itemize}
