
\section{Aims}\label{sec:objectives}

\subsection{General Aim}

To develop a medical image semantic segmentation framework for
multi-annotator contexts that encodes expert-specific knowledge,
manages low-quality data, and addresses annotation variability in
histopathology applications.

%----------------------------------------------------------------------
\subsection{Specific Aims}

\begin{itemize}

  \item To propose a novel loss function for image semantic
    segmentation that infers the underlying ground-truth mask while
    modeling sample-dependent annotator reliability, thereby
    addressing variability and disagreement across annotations.

  \item To introduce a tensor map which codifies the reliability of
    each labeler based only on the inputs, allowing the model to
    implicitly weigh the labelers based on their performance across
    the mask and classes space.

  \item To implement a deep learning–based approach for image
    semantic segmentation that integrates the proposed
    tensor-extended loss function, evaluating its effectiveness on
    histopathology detection tasks.

\end{itemize}
