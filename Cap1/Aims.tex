
\section{Aims}\label{sec:objectives}

\subsection{General Aim}

The main purpose of this work is to adaptively infer the best possible
segmentation in \gls{ISS} tasks for medical images through a novel
approach, without needing separate inputs about the labeler while
offering an interpretable reliability space per labeler and properly
facing the performance inconsistency across the annotators space and
the variability of images quality.

%----------------------------------------------------------------------
\subsection{Specific Aims}

\begin{itemize}

  \item To develop a novel loss function for \gls{ISS} tasks in
    medical images, which accurately infers the underlying ground
    truth segmentation mask without needing separate inputs about the
    labeler performance.

  \item To introduce a tensor map which codifies the reliability of
    each labeler based only on the inputs, allowing the model to
    implicitly weigh the labelers based on their performance across
    the mask and classes space.

  \item To develop and test a deep learning model for \gls{ISS} tasks
    in medical images, which can learn from inconsistent labels and
    improve the segmentation performance compared to other solutions
    in state of the art.

\end{itemize}
